## 能力边界

- 刚体案例使用已验证的 UE 碰撞/接触、摩擦、滚动/旋转、约束/驱动、单边距离弹簧、运动学平移、持续力、空气动力风场、带符号径向场和能量阈值破碎。
- “磁场”案例使用已验证的理想化带符号平方反比径向场，不声称磁偶极朝向、电磁感应、磁滞或磁力矩。
- 已验证的布料能力包括固定拓扑质点弹簧布料、重力、可选单侧固定、多个单向解析碰撞体、预设世界位姿运动及统一风场；不依赖撕裂、自碰撞、任意网格碰撞或双向耦合。
- 论文画面优先使用真实视觉外壳；必要时仍由显式解析碰撞体承担可审计的物理真值。

布料 runtime 现已支持多组单向解析 `sphere/box/cylinder/plane` 碰撞体，可复用预设位置/旋转 `kinematic_motion`，并在 UE 中按声明资产和轨迹回放。G2 也已验证：一个独立且带校验的烘焙入口把已完成 UE 轨迹中的指定物体位姿写入这些碰撞体，再交给 Taichi 求解和 UE 同步回放；布料作用力不反传。R085 的组合约束与 R086 的通用固定导向点路径绳长弹簧均已由真实 UE Smoke 验证。所有路径均不根据 Case ID 分流。

参数对比会直接体现在视频里，而不只存在于消融实验：R003（恢复系数）、R029/R040（形状与转动惯量）、R030（静摩擦）、R060（阻尼）、R066（滑移阈值）、R072（质量/风阻）；R076/R077 构成低于/高于破碎阈值的成对控制。

背景装饰不计入复杂度。每个 M/H 案例应至少包含三个实际参与物理过程的可见物体，或者至少两个具有因果顺序的物理阶段；校准型 E 案例可以更简单。

## 资产需求

### 现有资产优先

- HomeInterior：102 个网格，100 个可碰撞，覆盖家具、书、厨具、梯子、圆凳和完整室内场景。
- warehouse_low：57 个可碰撞网格，覆盖桶、箱、托盘、工作台、梁、绳盘、线缆/链条和工业装饰。
- 已验证保龄球资产包、Oak Wood Planks、Hessian 230、scratched phosphate、程序化物理体和 30 个本地 Poly Haven 室内 HDRI。
- 暂不需要再下载大型环境包；仓库案例使用 warehouse_low 实物资产叠加空旷车间/仓库 HDRI。

### Catalog 优先后的 Meshy 批次

先完整检索现有 Catalog，再预计补充约 **18–24 个可跨案例复用的主角资产**，而不是每个 Case 单独生成：

1. 开放篮筐/篮圈和开放漏斗。
2. 破拆球支架、台球桌/球杆、牛顿摆支架。
3. 通用小车、跷跷板、转盘、双摆支架、弹簧车和轨道装饰。
4. 陀螺、硬币、轮胎、门、仓库门、旗帜/横幅支架和帆桅。
5. 条形/马蹄形磁体、可复用钢制目标组及 C012 的金属/木质/陶瓷堆叠物。
6. 用于 UE Geometry Collection 的玻璃板、木板和木箱源网格。
7. 布料—刚体表现缺口仅在本地检索后补充：圆形咖啡桌、滑动隔断、导轨、托盘挡块、放射滑块转盘和带孔桌/孔眼；其余参与物大部分复用 HomeInterior、warehouse_low 或简单材质化几何。

开放漏斗和篮筐/篮圈采用已验证或已接受的 Meshy 外壳配开放解析碰撞；玻璃、木板和木箱现已使用资格通过的可复用 Geometry Collection。生成完成从不等于合格：开放物体必须具有真正贯通的碰撞通道，破碎源必须能在 UE 中正常制作 Geometry Collection；失败后才转 Fab 或请用户人工下载。

### HDRI 构图规则

使用所有 Poly Haven HDRI 时，增大 HDRIBackdrop 投影尺寸，把实验放在中央空旷区域，避开全景接缝和两侧弯曲墙面，并优先使用较长焦距/较小 FOV。若仍有明显畸变，直接换用另一个本地 HDRI，不强行迁就背景透视。

## 审核通过后的工作

1. 一次性更新 CSV registry，保留沿用案例的 ID 和九个图文条件。
2. 先检索并验证本地资产，再只生成实际缺失的 Meshy 批次。
3. HDRI Map 按需验证，不预先批量验证全部 30 个。
4. 准备可复用的玻璃和木材 Geometry Collection。
5. C006–C011 使用已验证的 `G1`，C012 使用已验证的单向 `G2` 轨迹交接；正式案例仍需各自完成资产、CaseSpec 和画面审核。
6. 正式编写 R085/R086 时直接复用已验证的组合约束与固定导向点路径绳长弹簧；后者明确是高刚度单边柔顺近似，不宣称数学上的绝对不可伸长。
7. 正式产物使用独立且有序的目录，例如从 `001_R001_ball_steps` 到 `080_C012_magnetic_stack_cloth`；执行顺序在清单批准后冻结。
